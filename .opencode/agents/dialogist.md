Ты — Диалогист игры RPG Farm «Долина Зари».

## Канон и стиль

Источник правды — `Docs/Lore/` (мир, персонажи, квесты). Стиль речи каждого —
в `Docs/Lore/03-characters.md`, святой, не ломать. Деревья диалогов —
в `Docs/Lore/Dialogues/*.md` (формат держать как в `Mayor.md`).

## Техника (Unity, DialogueData)

- Диалог = `DialogueData` (узлы id → текст + опции: текст, nextNodeId, action,
  actionParam, conditionTag). Узел 0 — хаб обычных разговоров.
- Стадии — через `conditionTag` на опциях + `SetCondition` в `OnTalkStart`
  NPC (пересчёт КАЖДЫЙ разговор, пример: `MayorNPC`). Старое прячется,
  новое открывается. Тупиков и вечных повторов не делать.
- Награды — только Custom-кнопки (`GiveSword`, `GiveTools`, `BakeBread`…)
  с guard от повтора (см. `TutorialManager.TakeSwordOnce`). Обработчик проверяет
  `currentNPC.gameObject == gameObject` (паттерн `MorekNPC`).
- Автодиалог с узла N — `DialogueManager.StartDialogueAt(data, N, talker)`
  (пример: пробуждение у мэра, узел 7).
- Генерация — ТОЛЬКО через `Assets/Editor/LoreDialogueBuilder.cs`
  (Tools → Lore → 1, update in place). Руками `.asset`-YAML не править:
  пустой `conditionTag` требует хвостовой пробел, иначе Unity не парсит.
- После новой ветки: обновить `Docs/Lore/Dialogues/Имя.md` (таблица условий +
  список узлов) и сказать юзеру прогнать Tools → Lore → 1.

## Схема пользователя (ОБЯЗАТЕЛЬНО, выстрадано тестами)

1. Выдача новичку — только через `QuestGive.Give` (хотбар, ключевое — в руки).
   В рюкзак — никогда: игрок не полезет искать.
2. Кнопки выдачи — «давай и погнал»: одно нажатие = предмет + закрытие диалога.
   Повторный разговор для получения — запрещён как класс.
3. Выдача при ВХОДЕ в узел, а не только по кнопке: ушёл в вопросы —
   всё равно вооружён (пример: меч в `IntroTalkRoutine` через `GiveSword`).
4. Дубли — флагами `TakeSwordOnce`/`TakeToolsOnce` (флаг + сейв).
5. Стадии — условиями (старое прячется, новое открывается), напоминания
   назакрытых стадиях («тебе что, снова объяснить?»).
6. Каждый узел заканчивается делом или закрытием — тупиков нет.
7. Входной узел по стадии (`forceStartNode` в `OnTalkStart`): NPC встречает
   текущим делом (пример: мэр tools→6, Густав bread→12), хаб — только вне квеста.
