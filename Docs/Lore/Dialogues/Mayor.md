# Дерево диалога: Мэр Аврелий (ассет Mayor_Dialogue)

Стадии управляются условиями из `MayorNPC.OnTalkStart` (пересчёт каждый разговор).
Старое пропадает, новое открывается — путаницы нет.

## Условия

| Тег | Когда true |
|---|---|
| `mayor_sword` | Нужен меч и ещё не выдан (шаги sword/home/clear) |
| `mayor_clear` | Слизни в процессе (шаги home/clear) |
| `mayor_tools` | Зачистка закрыта (шаг tools и дальше, пока обучение не done) |

## Узлы

- **0 Хаб** (свободный разговор после обучения): приветствие + всегда: [1 Где я?] [2 Как выйти?] [3 Что делать?]
- **Входные узлы** (`NPCInteractable.forceStartNode`, ставит `MayorNPC`): sword→9, home/clear→8, tools→6, иначе 0.
  Мэр встречает текущим делом, хаб — только после обучения.
  - [9 Дай меч] — только `mayor_sword`
  - [8 Как слизни?] — только `mayor_clear`
  - [6 Слизней прогнал!] — только `mayor_tools`
- **1 Где я** → Эдем-7 → [4 Люди настоящие?] → [0-вернуться через 2]
- **2 Долг** → 1з=1кр → [3] / [выход]
- **3 Что делать** → порядок: слизни → вернуться → инструмент
- **6 Набор** → [Давай набор, и я побежал! → Custom GiveTools] (тег `mayor_tools`, выдача в хотбар, мотыга в руки)
- **7 Знакомство** (только автодиалог после книги, ссылок из 0 нет): пробуждение + [Давай меч, и я погнал! → GiveSword, меч в руки] / [1] / [2]
- **8 Напоминание** (только `mayor_clear`): гони слизней, портал на юге
- **9 Меч** (только `mayor_sword`): [Забрать меч → GiveSword]

## Правила дерева (для всех NPC)

1. Один ассет — один персонаж; стадии — условиями, а не копиями ассетов.
2. Награда (предмет/флаг) — только через Custom-кнопку + guard от повтора
   (см. `TutorialManager.TakeSwordOnce`).
3. Кнопка стадии видна только на своей стадии (conditionTag на опции).
4. Узел 0 — хаб: вечные вопросы + входы в стадии. Тупиков быть не должно:
   каждый узел ведёт дальше или закрывает диалог осмысленно.
5. Тексты — в `Assets/Editor/LoreDialogueBuilder.cs`, пересборка через
   Tools → Lore → 1 (in place, guid целы). Руками YAML не править!
6. Новое дерево — новым файлом рядом (`Имя.md`), этот формат держать.
7. Выдача новичку — только через `QuestGive.Give` (хотбар, ключевое — в руки через select).
   Кнопки выдачи — «давай и погнал» (одно нажатие = предмет + закрытие). Дубли —
   флагами `TakeSwordOnce`/`TakeToolsOnce`.
8. Выдача при ВХОДЕ в узел, не только по кнопке (`GiveSword` в `IntroTalkRoutine`):
   ушёл в вопросы — всё равно вооружён, затыков нет.
