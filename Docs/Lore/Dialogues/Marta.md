# Дерево диалога: Марта (ассет DialogueSeedTrader)

Прилавок БЕЗ диалога переведён на диалог (паттерн мэра): на объекте
NPCInteractable + TraderNPC + MartaNPC. Товар переезжает сам
(`TraderNPC.Awake` забирает массивы у `ShopInteraction` и удаляет его).
Два `IInteractable` на объекте конфликтуют (детектор берёт первый) — так нельзя.

## Условия

Условий нет — советы висят всегда. Входной узел: шаг seeds → 12, иначе 0.

## Узлы

- **0 Хаб**: [Показать семена → магазин] [Что взять новичку? → 12] [Расскажи про книгу прокачки → 13] [Давно здесь? → 10] [Пока]
- **10 Давно** → 11 (100 тыкв → дыня/арбуз)
- **12 Совет** → магазин / выход
- **13 Книга** (3 очка/уровень, вкладки, перки семян/снаряжения) → [Где открывается? → 14] / выход
- **14 Где книга** — ЗАГЛУШКА: «спроси мэра» (настоящее место кнопки уточнить у владельца и переписать!)
