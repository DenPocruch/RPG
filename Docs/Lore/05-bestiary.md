# 05. Бестиарий

## Уже в игре (не трогать лор, только именовать)

- Слайм (6 цветов x Small/Big/Средний) — сгустки невычищенного кода. Beginner Forest, шахта 1-10. Дроп: медь Common.
- Микот (5 цветов) — грибница сервера, переваривает баги. Лес глубже.
- Гоблин-копейщик / лучник — одичавшие новички, лагерь в лесу. Дроп: железо Common. Лучник держит дистанцию, стрела через Attack.
- Ворона — чистильщик, клюёт урожай. Боится пугала (зона 3x3 / 5x5).
- Пчела — индикатор стабильности. Улей 12 мин, 2 пчелы, соты 50г.
- Venom Bloom (арт есть) — босс-цветок чащи, вирус.
- Sprout Slime (арт есть) — босс-вирус теплицы.
- Spike (арт есть) — ловушка/страж шахты.

## Запас (дорисовать → куда селить)

- **Скелет** — удалённые аватары. Шахта 11-20 (железо). Пациент выписался, тело осталось. Гремят, медленно идут. Дроп: железо, кости.
- **Голем** — сторожа ядра. Шахта 21-30 (золото/серебро). Корявость = норма. Медленные, толстые. Дроп: руда тира.
- **Маг (несколько)** — отступники, научились хакать. По одному на этаж 31+ как мини-босс. Финал — Маг-Охранник ядра (взлом с Дроном). Самонаводящиеся болты (реюз MagicBolt).
- **Бандит** — нарушители, грабят новичков. Дорога Ферма-Город-Лес + лагерь гоблинов. Лидер — человеческий босс Акта 2.
- **Энт** — защитники Сердца Леса. Не враги по дефолту. Просыпаются от рубки. Квест на дружбу.
- **Циклоп** — смотритель маяка, забаговался и вырос. Утёс пляжа. Бьёт бревном. Дроп: ключ от маяка.
- **Привидение** — «эхо», слепки умерших в реале. Часовня ночью + шахта 3 этаж. Не атакуют. Дают мини-квесты «передай / дострой». Полупрозрачный спрайт — рисовать минимум.

## Правило расселения

Не селить куда попало. Смотри `02-locations.md`:
лес = баги/одичавшие, шахта = глубже = старше данные = злее, пляж = 1 босс, город = безопасно (только привидения ночью).
