# Долина Зари — оглавление лора

Единственный источник правды для агента `lorekeeper`.

## Главные якоря (не менять молча)

- Реальный мир: 2041 год, корпорация «ВитаКор», система «ЭДЕМ-7» — реабилитационная виртуалка.
- Герой: Илья (ник Дуги), 32 года, электрик. Сбит машиной в 23:47 у остановки «Заводская».
- Тело в капсуле. Мозг в виртуалке. Ферма/бой/рыбалка = нейро-гимнастика.
- Долг: **500 000 кредитов**. Курс: **1 золото = 1 кредит**.
- Название мира внутри: Долина Зари. Пациенты говорят «Долина».
- Мэр Аврелий — ИИ-куратор, единственный не-человек. Остальные NPC — пациенты.
- Тон: тёплый, грустный, без пафоса. Никаких «избранных».

## Файлы

- `01-world.md` — рамка, правила Эдема, интро-книга (4 страницы).
- `02-locations.md` — Ферма №9, Город Заря, Лес Новичков, Пляж, Шахта + точки под новых врагов.
- `03-characters.md` — NPC: стиль речи, тайна, 3 слоя реплик.
- `04-quests.md` — главный квест в 3 актах + побочки + доска заказов + слухи/записки.
- `05-bestiary.md` — кто уже есть + запас (маги, скелет, големы, бандиты, энты, циклоп, привидения).

## Как пользоваться

1. Хочешь добавить NPC/место/квест — сначала прочитай нужный файл.
2. Противоречие? Предложи 2 варианта: вписать без ломки / что переписать.
3. Команда «запомни» = агент правит файл через edit, без дубликатов.
