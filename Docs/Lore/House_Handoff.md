# Конструктор дома — слепок сессии для переноса в другой чат (04.10.2026)

Полный концепт: `Docs/Lore/House_Planning_Concept.md` (§1–11). Этот файл — только
факты сессии: что закодировано, что проверено, где застряли, что дальше.

## 1. Что за фича
Режим планировки дома в стиле Hay Day: чертеж → панель-каталог (Полы/Стены/
Мебель/Расширение/Магазин) → перекраска по тайлам со свопом склада → пристройка
+1 тайл (вбок/вверх, 50 дерева + 500g, +25/+250 каждые 5) → мебель (пол/стена).
Панель верстает владелец в SampleScene/Canvas (фаза 7), код только подключается.

  ленты), косяки 118/116, порог 12, фон 76. Сарай-стиль: пол 65, лента
  405-407/457-459 (для механики; ring shared). Две плитки 65 на (-87,9/10) —
  остатки, под замком по имени (`lockTileNames`: 118/116/12/65).
- Пол без коллайдера (у InteriorFloor его нет), стены TilemapCollider2D+Composite
  (пересобирается сам). Вход/выход — парные телепорты, сквозь дверь не ходят.
- Правила автотайлера (HouseAutotiler.cs): member = пол ИЛИ лента; скоп = bbox
  пола ±4 (шальная лента вне — варнинг); одиночные маски смотрят продолжение
  (кольцо с обеих = колонна V, с одной = кромка H); углы 2-dir: обе снаружи
  кольцо = вогнутый, одна = прямая, иначе выпуклый; пустая маска + 1 диагональ
  (в пусто/ленту + оба ортогонала кольцо) = угол; свежим клеткам фон сносится;
  Stabilize() гоняет compute+paint+долив до стабильности (макс 4).

## 5. Где застряли (открытая проблема)
Тест-14 построил (-89,11): +1 пол, 1 стена, 0 расхождений — но визуально левый
угол кривой (старый угол (-88,11) стал вертикалью вместо продолжения ряда).
Причина найдена: одиночные маски {E}/{W} всегда давали straightV; исправлено
(продолжение с обеих = V, с одной = H) + Stabilize. Код исправлен, владелец
ЕЩЁ НЕ ПЕРЕПРОВЕРИЛ (нужно: компиляция чистая → 14 → Ctrl+S → Play).
- Хроника глюков сессии (чтобы не повторять): (а) мой лишний `}` ломал сборку —
  исправлен, все файлы проверены (баланс скобок 0); (б) владелец жал 14–16 в Play
  (там отказ по дизайну) и 17 вне Play — правильно: 11–16 вне Play, 17 в Play;
  (в) файл сцены и открытая сцена НЕСКОЛЬКО РАЗ расходились (ручная докраска
  без Ctrl+S) — весь анализ ехал мимо. ПРОТОКОЛ: красит/сейвит → пишет
  «сохранено» → ассистент только тогда читает файл.
