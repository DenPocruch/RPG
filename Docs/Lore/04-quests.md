# 04. Квесты

## Главный квест (3 акта)

### Акт 1. ПАЛАТА (план v5 — полный порядок первого дня, принят владельцем)
Принцип: игрок не должен знать интерфейс заранее — квест заставляет открыть
нужную систему в нужный момент. Подсветка кнопок — стрелкой (SetUITarget).
ИНТРО → МЭР → УПРАВЛЕНИЕ → ИНВЕНТАРЬ → ХОТБА → ФЕРМА → БОЙ → ЛУТ →
ИНСТРУМЕНТЫ → МОТЫГА(1+5) → ПОСАДКА → ПОЛИВ → ГОРОД(знакомства+магазин) →
РОСТ(ждём) → УРОЖАЙ → ПОДБОР → ПРОДАЖА(−долг) → ГОТОВКА → ЕДА → НАВЫКИ →
РЫБАЛКА(лёгкая первая) → ЛЕС → ШАХТА(кирка T1) → КУЗНИЦА(апгрейд) →
ЭКИПИРОВКА(надеть) → +500g → СВОБОДНАЯ ИГРА (Акт 2 «Долги»).
Формат квестов: ID → название → NPC → текст → условие → подсветка → награда → next.
Доска/животные/пчёлы/станки/глубокая шахта — только Акт 2.
Исключение из «всё в хотбар»: набор идёт В РЮКЗАК — это урок хотбара
(найти мотыгу → перетащить). Меч/хлеб/кирка — как обычно в хотбар и в руки.

### Акт 1. ПАЛАТА (путеводитель v4 — TutorialManager, сейв `lore_tutorial` ver=4)
Порядок один: книга → пробуждение на площади (телепорт в City + автодиалог мэра, узел 7, меч) →
возврат на участок → зачистка (15 учебных слаймов) →
мэр в городе (набор: мотыга+серп+лейка+6 пшениц, кнопка под условием mayor_tools) →
6 грядок (копай/сажай/полей, колодец со стрелкой) → 6 пшениц → Густав (хлеб за 2) →
съесть → Марта (купить семена) → Дрон (продать) → прокачка → хвост (удочка/рыба/лес/шахта).
Стрелка QuestArrow на каждом шаге (портал/NPC/колодец/враг/жила; eat/skills без стрелки).
Меча в старте нет. FarmMayorNPC.cs не используется (мэр один, в городе) — резерв.
Миграция: старые сейвы начинают цепочку заново без перечитывания книги.
0. intro — закрой книгу (IntroBookUI, 3 страницы, 1 раз) → `Notify("intro_done")`
1. hoe — вскопай 1 грядку (хук FarmInteraction.TillGround)
2. plant — посади семена (хук PlantSeed)
3. water — полей (хук WaterGround; воду — из колодца)
4. harvest — собери серпом (хук HarvestCrop)
5. sell — продай Дрону (хук BuyerManager.Sell)
6. rod — возьми удочку у Морека (хук MorekUI.GiveRod)
7. fish — поймай 1 рыбу (хук FishingController)
8. kill — убей 3 слаймов в лесу (хук EnemyHealth.Die, счётчик 3)
9. mine — добудь 5 жил в шахте (хук OreVeinComponent.DepleteVein, счётчик 5)

Пугало/вороны, Густав/Степан/Марта, курица+кормушка — в книге упомянуты, в трекер НЕ входят (переедут в побочки ч.4, чтобы не плодить хрупкие хуки).

### Акт 2. ДОЛГИ (свободная игра)
- Открыты животные, пчёлы, станки (вино 250 / сыр 150 / масло 120 / джем 130).
- Цепочки NPC по 3-5 квестов (см. 03-characters).
- Доска заказов = ежедневки (уже есть OrderBoardUI).
- Ночью привидения: «...не верь счётчику...», «...нас не выписывают...».

### Акт 3. ВЫБОР
- Правда про проценты (500к → ~750к).
- Дрон зовёт в ядро через шахту, мимо големов, к Магу-Охраннику.
- 3 финала: честно / взлом / остаться (NG+).

## Побочки (оживление)

- Густав: звёздные овощи → «Суп как у мамы».
- Степан: обсидиан → меч + «Руки вспомнили».
- Мира: 100 тыкв → дыня/арбуз.
- Морек: 43 рыбы → лодка + уход.
- Боря/Доря: общий дом.
- Энты: не рубить 3 дня + 10 сот → золотое дерево.
- Бандиты: привести лидера мэру живым.
- Циклоп: ключ от маяка.
- Привидения: «передай / дострой» — 5 мини-историй.

## Доска заказов — писать как истории

Плохо: «Нужно 5 пшеницы».
Хорошо: «Боря поспорил с Дорей, что испечёт хлеб сам. Спасите семью, принесите пшеницу. — Жена Бори».

## Живость за копейки

1. Слухи (20 строк, ротация у торговцев): «Говорят, в шахте скелеты ходят...», «Морек опять про рыбу-дом брешет».
2. Записки (10 шт): дневник фермы №9, отчёт врача, письмо Дрона.
3. Погода как персонаж: дождь = «сервер чистят», туман = «привидения близко». Иконки уже в `Art/UI`.
4. Имена врагов через лор: «Слайм-баг. Угроза: низкая. Рекомендована агро-терапия».
