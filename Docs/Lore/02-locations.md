# 02. Локации

## Ферма №9 (SampleScene) — «палата» игрока

Заброшенный участок. Прошлый пациент выписался (или нет — записка в доме намекает).
Выдают игроку как жильё + терапию.

Лор-привязки механик:
- Вороны = «чистильщики», клюют нестабильные данные (урожай). Пугало = старый firewall.
- Пчёлы = индикатор здоровья сети. «Где пчёлы — там стабильно».
- Станки (вино/сыр/масло/джем) = «дието-цех». Качество входа → качество выхода.
- Пугало, кормушка, поилка, улей — ставятся ghost-режимом, собираются молотком (уже в коде).

## Город Заря (City) — центральный сервер

Единственное безопасное место. Здесь нельзя умереть.
Что есть: дом мэра, лавка Миры (семена), Кузнец Степан, Густав (кухня), Скупщик Дрон, дома Бори/Дори, доска заказов, часовня привидений, портал на пляж, вход в шахту.

Добавить по лору (ч.3, скрипты готовы — расстановка руками):
- Мэр: дубликат любого NPC в City + компонент MayorNPC (диалог подтянется сам). Место — у фонтана в центре.
- Часовня: угол карты + 2-3 GhostEcho (любой спрайт-заглушка, тинт сам; realNightOnly по желанию).
- Лагерь бандитов (Лес): 2-3 гоблина-префаба (GoblinSpear/Archer) + костёр из Exterior.
- Маяк (Пляж, утёс): высокий проп + LockedDoor с текстом про запах. Циклоп и ключ — ч.5.

## Лес Новичков (Beginner Forest) — окраина симуляции

Дикая, плохо отрендеренная зона. Отсюда баги.
- Слаймы = сгустки невычищенного кода.
- Микоты = грибница сервера, переваривает баги.
- Гоблины (копья/луки) = одичавшие новички, сбились в лагерь, не хотят работать.
- Сердце Леса (дальний угол) = энты. Спят. Просыпаются если рубить рядом. Квест на дружбу: не рубить 3 дня + 10 сот → семя золотого дерева.
- Лагерь бандитов (дорога Ферма-Город-Лес) = нарушители, грабят новичков. Лидер — первый человеческий босс. Квест от мэра: разберись, но приведи живым.
- Теплица/поляна = Sprout Slime (босс-вирус), чаща = Venom Bloom (босс-цветок). Арт уже есть в `Art/Enemy`.

## Пляж (Beach) — зона релаксации

Бывший курорт для тахикардии, почти заброшен. Остался Морек.
- 3 FishingSpot, 43 вида рыбы (18 река + 25 море) = «морской архив успокоения».
- Легендарная рыба = удалённые админом «кошмары», Морек просит поймать.
- Утёс над пляжем = Циклоп, старый смотритель маяка, забаговался и вырос. Бьёт бревном. Дроп — ключ от маяка.

## Шахта (Mine) — технический спуск к ядру

Чем глубже — тем старее данные и злее охрана. 5 этажей вручную + лестницы.
- 1-10: камень/медь. Слаймы, гоблины.
- 11-20: железо. Скелеты = удалённые аватары (пациент выписался, тело осталось).
- 21-30: золото/серебро. Големы = сторожа ядра. Должны быть корявыми.
- 31+: кристаллы/обсидиан. Маг-отступник на этаж как мини-босс. В финале — Маг-Охранник ядра (взлом с Дроном).
- Привидения на 3 этаже = «эхо», записи умерших в реале. Не атакуют, просят: «передай...», «дострой...».

Освещение: тусклый глобальный свет + факел игрока. Смерть в шахте = выход на поверхность + потеря % золота.
